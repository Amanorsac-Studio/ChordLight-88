CHORDLIGHT 88 1.5.2
Amanorsac Studio · amanorsac.studio


WHAT THIS IS

An 88-key MIDI display that lights the notes you play, names the chord,
and reads the Nashville number in your key — while your DAW keeps the
same keyboard.


INSTALLING

Windows    Run Chordlight88-1.5.2-Windows.exe and follow the installer.
macOS      Open Chordlight88-1.5.2-macOS.dmg and drag Chordlight 88 to
           Applications.


WHAT GETS INSTALLED

Standalone    C:\Program Files\Amanorsac Studio\Chordlight 88\
              /Applications/Chordlight 88.app

The installer shows this path and lets you change it.


YOUR SETTINGS AND RECORDINGS

Windows    Documents\Amanorsac Studio\Chordlight 88\
macOS      ~/Documents/Amanorsac Studio/Chordlight 88/

Uninstalling does not delete these.


NO ACTIVATION

There is no key and no account. It never connects to the internet.


IF IT DOES NOT SEE YOUR KEYBOARD

1. Open Setup and check MIDI input. "All inputs" hears every port.
2. Chordlight never takes a port for itself, so leave your DAW and
   Kontakt open — they all hear the same keyboard.
3. A controller with an exclusive-access driver can be shared through
   loopMIDI.

Still missing? hello@amanorsac.studio


UNINSTALLING

Windows    Settings > Apps > Chordlight 88 > Uninstall
macOS      Drag /Applications/Chordlight 88.app to the Bin, then delete
           ~/Library/Application Support/Amanorsac Studio/Chordlight 88/
           if you want the window positions gone too.
